# Simple Interest Calculator

A simple Bash script application designed to calculate simple interest based on user inputs.

## Overview
This project was created as part of the IBM Git and GitHub Final Project. It allows users to input the Principal amount, Rate of Interest, and Time period to compute the final simple interest value.

## Usage
Run the Bash script using:
```bash
bash simple-interest.sh

Inputs
Principal (P): The initial amount of money.
Rate (R): Annual interest rate (percentage).
Time (T): Time period in years.
